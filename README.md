# PharmRepurpose-DB

An open-source database and parsing tool dedicated to mapping drug repurposing (repositioning) data from scientific literature. 

## Project Goal
To provide pharmacy students and academic researchers with structured, free data (JSON/Markdown) on alternative therapeutic pathways for established compounds, bypassing expensive proprietary databases.

## Tech Stack (In Development)
- Python (for clinical trial scraping & parsing)
- Markdown & JSON (for data structuring)

*Currently in early-stage development.*
